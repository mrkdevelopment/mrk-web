# Google Search Console: your pages report

This report shows which pages on your current site people actually find through Google. We use it to make
sure the pages that matter most are kept, and that none of them is lost when the new site goes live.

## How to get it (about two minutes)

1. Open Google Search Console (search.google.com/search-console) and choose your website.
2. Click **Performance** in the left menu. It may be labelled "Search results".
3. Change the date range to **Last 12 months**.
4. Click the **Pages** tab above the table.
5. Click **Export** at the top right, then **Download CSV**.
6. Put the file you get in this folder. It is a zip: there is no need to unzip it.

## If you do not have access

- **It is a client's site:** ask them to add you in Search Console under Settings, Users and permissions,
  Add user. "Restricted" access is enough. Or send them the six steps above.
- **Search Console was never set up:** skip this. The site is still read page by page, and Search Console
  is set up when the new site goes live.
