# Installing MRK-Web

For Claude, when asked to install this. Do exactly this and nothing more.

1. Copy the folder `skills/mrk-web` from here to:
   - **this project:** `.claude/skills/mrk-web` in the project folder, or
   - **all projects:** `.claude/skills/mrk-web` in the person's home folder,

   whichever they asked for. Replace any older copy. If nothing was said, use this project.
2. Delete the unzipped copy. Leave the zip.
3. Reply with this one line, and nothing else:

   > MRK-Web is installed. Type `/mrk-web start` and your website address. (If that is not recognised,
   > restart Claude Code once.)

Do not run checks, list what was copied, explain the folder layout, or offer to install anything else. The
person is new to this. One line is what helps.
